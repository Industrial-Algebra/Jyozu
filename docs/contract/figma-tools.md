## Notes
- All tools are verified (live-verified in Figma session).
- The `channel` parameter is MCP-specific and should be managed by the provider session.
- Safety parameters like `confirm` and `dryRun` (for destructive tools) should be preserved.
- The provider should expose a Lonis-compatible interface: `manifest`, `tools list`, `tools describe`, `call`, `status`, `doctor`.
